# Convert text to speech and save a WAV file in Node

A script that sends text to Sonic and writes the audio to `hello.wav`.

## Prerequisites

- Node 22 or newer
- `npm install @cartesia/cartesia-js`
- `CARTESIA_API_KEY` set in your shell. `CARTESIA_VOICE_ID` is optional; the script falls back to a public voice.

## The script

```ts filename="speak.mts"
import { writeFile } from 'node:fs/promises';
import Cartesia from '@cartesia/cartesia-js';

const client = new Cartesia({ apiKey: process.env.CARTESIA_API_KEY });

const response = await client.tts.generate({
  model_id: 'sonic-3.6',
  transcript: 'Hello from Cartesia. This file was generated by a Node script.',
  voice: process.env.CARTESIA_VOICE_ID ?? 'db6b0ed5-d5d3-463d-ae85-518a07d3c2b4',
  output_format: { container: 'wav', encoding: 'pcm_s16le', sample_rate: 44100 },
});

await writeFile('hello.wav', Buffer.from(await response.arrayBuffer()));
console.log('Wrote hello.wav');
```

Run it with a TypeScript runner such as `npx tsx speak.mts`.

## How it works

`tts.generate` returns a `Response`. For a `wav` container, `output_format` also needs an `encoding` and a `sample_rate`. Here that is 16-bit PCM at 44.1 kHz. The SDK adds the `Cartesia-Version` header on its own, so there is nothing to configure.
