# Python

Recipes that use the `cartesia` Python package. The 4.x client needs the key passed as `api_key=`.

- [Convert text to speech and save a WAV file in Python](./01-generate-speech-to-file.mdx): one `tts.generate` call with Sonic 3.6.
- [Transcribe an audio file with ink-whisper in Python](./02-transcribe-an-audio-file.mdx): the transcript, its duration and word timestamps from one request.
- [Clone a voice from a short recording in Python](./03-clone-a-voice.mdx): create an instant clone, speak with it, and delete it.
- [Add voice mode to Claude Code, Cursor or Codex](./05-voice-mode-for-coding-agents.mdx): an MCP server that speaks with Sonic 3.6 and listens with Ink 2 turn detection.
- [Turn an EPUB ebook into an audiobook with Python](./10-ebook-to-audiobook.mdx): a voice per speaker, emotion cues, and word timestamps for read-along.
