# Convert text to speech and save a WAV file in Python

A script that sends text to Sonic and writes the audio to `hello.wav`.

## Prerequisites

- Python 3.9 or newer
- `pip install cartesia`, or `uv add cartesia`
- `CARTESIA_API_KEY` set in your shell. `CARTESIA_VOICE_ID` is optional; the script falls back to a public voice.

## The script

```python filename="speak.py"
import os

from cartesia import Cartesia

client = Cartesia(api_key=os.environ["CARTESIA_API_KEY"])

response = client.tts.generate(
    model_id="sonic-3.6",
    transcript="Hello from Cartesia. This file was generated by a Python script.",
    voice=os.environ.get("CARTESIA_VOICE_ID", "db6b0ed5-d5d3-463d-ae85-518a07d3c2b4"),
    output_format={"container": "wav", "encoding": "pcm_s16le", "sample_rate": 44100},
)

response.write_to_file("hello.wav")
print("Wrote hello.wav")
```

Run it with `python speak.py`, or `uv run speak.py`.

## How it works

`tts.generate` returns a binary response, and `write_to_file` saves its bytes. The SDK sets the `Cartesia-Version` header itself.
