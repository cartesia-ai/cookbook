# Transcribe an audio file with ink-whisper in Python

To turn a finished recording into text with Cartesia, send the file to the speech to text endpoint with the `ink-whisper` model. One request returns the full transcript, the audio's duration and, if you ask, a start and end time for every word.

## Prerequisites

- Python 3.9 or newer
- `pip install cartesia`, or `uv add cartesia`
- `CARTESIA_API_KEY` set in your shell
- An audio file: flac, m4a, mp3, mp4, mpeg, mpga, oga, ogg, wav or webm

## The script

```python filename="transcribe.py"
import os
import sys

from cartesia import Cartesia

client = Cartesia(api_key=os.environ["CARTESIA_API_KEY"])

path = sys.argv[1] if len(sys.argv) > 1 else "meeting.m4a"
with open(path, "rb") as audio:
    result = client.stt.transcribe(
        file=audio,
        model="ink-whisper",
        language="en",
        timestamp_granularities=["word"],
    )

print(result.text)
print(f"{result.duration:.1f} s of audio")
for w in result.words or []:
    print(f"{w.start:6.2f} {w.end:6.2f} {w.word}")
```

Run it with `python transcribe.py meeting.m4a`, or `uv run transcribe.py meeting.m4a`. On the `hello.wav` from [Convert text to speech and save a WAV file](./01-generate-speech-to-file.mdx) it prints something like:

```text
Hello from Cartesia. This file was generated by a Python script.
3.9 s of audio
  0.00   0.22  Hello
  0.22   0.44  from
  0.44   1.26  Cartesia.
  1.26   1.64  This
...
```

## Which model do I use for a file?

`ink-whisper`. The other speech to text model, `ink-2`, is for live audio over a WebSocket and does not work on this endpoint. If your audio is still being recorded and you want text as people speak, see [Stream speech to text in real time with Ink 2](../05-node/04-real-time-speech-to-text.mdx).

## How do I transcribe a language other than English?

Pass its ISO 639-1 code, such as `language="es"` or `language="ja"`. The API defaults to `en` when you leave it out, so a Spanish file sent without `language` is transcribed as if it were English. `ink-whisper` covers about 100 languages, listed on the [older STT models page](https://docs.cartesia.ai/build-with-cartesia/stt/older-models). The response's `language` field echoes the code that was used.

## What comes back?

- `text`, the whole transcript as one string.
- `duration`, the length of the audio in seconds.
- `words`, only when you pass `timestamp_granularities=["word"]`. Each item has `word`, `start` and `end` in seconds. Words can carry a leading space, so strip them before you compare.

There are no speaker labels. If you need to know who said what, split the recording per speaker before you send it, or have an LLM infer speakers from names in the text.

## How do I call it from a web server?

The same call works inside a FastAPI or Flask route. Pass the uploaded file object as `file`. Keep the key on the server, and cap the upload size before you forward it. The Next.js version, with an LLM summary step after the transcript, is [Transcribe and summarize meetings in Next.js](../01-next/20-transcribe-and-summarize-meetings.mdx).

The 4.x Python client does not read `CARTESIA_API_KEY` from the environment by itself, so pass `api_key=` as above. The SDK sends the `Cartesia-Version` header for you.
