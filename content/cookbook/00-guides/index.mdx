# Guides

Short guides on the parts every voice app has to get right. Start here before the stack-specific sections. Commands in the recipes use npm and npx; pnpm works too.

- [Use Cartesia from the browser without exposing your API key](./01-browser-auth-with-access-tokens.mdx): mint a 60 second access token on the server and grant only `tts`, `stt` or `agent`.
