# Stream text to speech in Next.js

This recipe turns text into speech and starts playing it before the full audio exists. The route handler holds the API key and passes Cartesia's response bytes straight through. The page plays each chunk with the Web Audio API.

## Prerequisites

- A Next.js App Router app
- `pnpm add @cartesia/cartesia-js`
- `CARTESIA_API_KEY` and `CARTESIA_VOICE_ID` is optional in `.env.local`; the code falls back to a public voice.

## Server: the route handler

```ts filename="app/api/speak/route.ts"
import Cartesia from '@cartesia/cartesia-js';

const client = new Cartesia({ apiKey: process.env.CARTESIA_API_KEY });

export async function POST(req: Request) {
  const { text } = await req.json();
  if (typeof text !== 'string' || text.length === 0 || text.length > 1000) {
    return new Response('Invalid text', { status: 400 });
  }

  const response = await client.tts.generate({
    model_id: 'sonic-3.6',
    transcript: text,
    voice: process.env.CARTESIA_VOICE_ID ?? 'db6b0ed5-d5d3-463d-ae85-518a07d3c2b4',
    output_format: { container: 'raw', encoding: 'pcm_f32le', sample_rate: 44100 },
  });

  return new Response(response.body, {
    headers: { 'Content-Type': 'application/octet-stream' },
  });
}
```

The key never leaves the server, so the page needs no access token. Gate this route before you ship. As written, anyone who finds it can generate speech on your account.

The SDK sends the `Cartesia-Version` header for you. You don't set it.

## Client: play chunks as they arrive

```tsx filename="app/page.tsx"
'use client';

import { useState } from 'react';

const SAMPLE_RATE = 44100;
const BYTES_PER_SAMPLE = 4;

export default function Page() {
  const [text, setText] = useState('Hello! This audio plays while it is still being generated.');
  const [busy, setBusy] = useState(false);

  async function speak() {
    setBusy(true);
    try {
      const res = await fetch('/api/speak', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ text }),
      });
      if (!res.ok || !res.body) throw new Error(`Request failed: ${res.status}`);

      const ctx = new AudioContext({ sampleRate: SAMPLE_RATE });
      let nextStart = ctx.currentTime;
      let leftover = new Uint8Array(0);
      const reader = res.body.getReader();

      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        const bytes = new Uint8Array(leftover.length + value.length);
        bytes.set(leftover);
        bytes.set(value, leftover.length);
        const usable = bytes.length - (bytes.length % BYTES_PER_SAMPLE);
        leftover = bytes.slice(usable);
        if (usable === 0) continue;

        const aligned = new ArrayBuffer(usable);
        new Uint8Array(aligned).set(bytes.subarray(0, usable));
        const samples = new Float32Array(aligned);

        const buffer = ctx.createBuffer(1, samples.length, SAMPLE_RATE);
        buffer.getChannelData(0).set(samples);
        const source = ctx.createBufferSource();
        source.buffer = buffer;
        source.connect(ctx.destination);

        const startAt = Math.max(nextStart, ctx.currentTime);
        source.start(startAt);
        nextStart = startAt + buffer.duration;
      }
    } finally {
      setBusy(false);
    }
  }

  return (
    <main>
      <textarea value={text} onChange={(e) => setText(e.target.value)} />
      <button onClick={speak} disabled={busy}>
        {busy ? 'Speaking...' : 'Speak'}
      </button>
    </main>
  );
}
```

## How it works

1. `tts.generate` returns a standard `Response` whose body is a stream of raw 32-bit float samples.
2. The route returns that body unchanged, so bytes reach the browser as Cartesia produces them.
3. The page reads the stream, turns whole samples into an `AudioBuffer`, and schedules each buffer to start right after the previous one ends.

The browser ends the loop when the stream closes. The buffers already scheduled keep playing after that.
