# Transcribe and summarize meetings in Next.js

This recipe records a meeting in the browser and turns it into notes. One route handler sends the audio to Cartesia's `ink-whisper` model for a transcript. A second route handler asks an LLM for a summary, the decisions that were made and the action items, as validated JSON.

The two steps are separate routes on purpose. The page can show "Transcribing" and then "Writing notes", and if the LLM call fails you still have the transcript and can retry only that step.

## Prerequisites

- A Next.js App Router app
- `npm install @cartesia/cartesia-js ai zod @ai-sdk/openai @ai-sdk/anthropic`
- `lib/llm.ts` and `lib/limits.ts` from the [meeting-notes template](https://github.com/cartesia-ai/cookbook/tree/main/examples/meeting-notes). `getModel()` in `lib/llm.ts` imports both provider packages, and `lib/limits.ts` holds the size and length caps used below
- `CARTESIA_API_KEY` in `.env.local`
- `LLM_MODEL` in `.env.local`, as `provider/model`. `getModel()` calls OpenAI or Anthropic directly when `OPENAI_API_KEY` or `ANTHROPIC_API_KEY` matches the prefix. Any other id goes through the [Vercel AI Gateway](https://vercel.com/docs/ai-gateway), which needs `AI_GATEWAY_API_KEY` (or OIDC on Vercel).

## Server: transcribe

The routes read the key when a request comes in, so `next build` works with no environment set.

```ts filename="lib/cartesia.ts"
import Cartesia from "@cartesia/cartesia-js";

export class MissingKeyError extends Error {
  constructor() {
    super("CARTESIA_API_KEY is not set. Add it to .env.local and restart.");
  }
}

export function getCartesia(): Cartesia {
  const apiKey = process.env.CARTESIA_API_KEY;
  if (!apiKey) throw new MissingKeyError();
  return new Cartesia({ apiKey });
}
```

Both routes spend money, so each one gets an in-memory rate limiter of 10 requests a minute per client IP. It is per process and only slows casual abuse. `clientIp` trusts `x-forwarded-for` only where a proxy sets it: on Vercel it takes the first entry, with `TRUST_PROXY=1` it takes the entry your own proxy appended, and anywhere else every caller shares one bucket. A caller can write anything into that header, so keying on its raw first entry lets anyone skip the limit.

```ts filename="lib/rate-limit.ts"
export function createRateLimiter(limit: number, windowMs: number, now: () => number = Date.now) {
  const hits = new Map<string, number[]>();
  return function allow(key: string): boolean {
    const t = now();
    const recent = (hits.get(key) ?? []).filter((at) => t - at < windowMs);
    if (recent.length >= limit) {
      hits.set(key, recent);
      return false;
    }
    recent.push(t);
    hits.set(key, recent);
    if (hits.size > 1000) {
      for (const [k, v] of hits) if (v.every((at) => t - at >= windowMs)) hits.delete(k);
    }
    return true;
  };
}

export function clientIp(request: Request): string {
  const forwarded = (request.headers.get("x-forwarded-for") ?? "")
    .split(",")
    .map((part) => part.trim())
    .filter(Boolean);
  if (process.env.VERCEL) return forwarded[0] ?? "global";
  if (process.env.TRUST_PROXY === "1") return forwarded[forwarded.length - 1] ?? "global";
  return "global";
}

export function tooManyRequests(headers?: HeadersInit): Response {
  return Response.json({ error: "Too many requests. Try again in a minute." }, { status: 429, headers });
}
```

```ts filename="app/api/transcribe/route.ts"
import Cartesia from "@cartesia/cartesia-js";
import { getCartesia, MissingKeyError } from "@/lib/cartesia";
import { MAX_AUDIO_BYTES, normalizeLanguage } from "@/lib/limits";
import { clientIp, createRateLimiter, tooManyRequests } from "@/lib/rate-limit";

const UPSTREAM_ERRORS: Record<number, string> = {
  400: "Cartesia could not read this audio. Try MP3, M4A, WAV, WebM or FLAC.",
  401: "The Cartesia API key was rejected. Check CARTESIA_API_KEY.",
  402: "The Cartesia account is out of credits.",
  413: "The audio file is too large for Cartesia.",
  429: "Cartesia is rate limiting this account. Try again in a minute.",
};

export const runtime = "nodejs";
export const maxDuration = 60;

const allow = createRateLimiter(10, 60_000);

export async function POST(req: Request) {
  if (!allow(clientIp(req))) return tooManyRequests();
  let form: FormData;
  try {
    form = await req.formData();
  } catch {
    return Response.json({ error: "Send the audio as multipart form data" }, { status: 400 });
  }

  const file = form.get("file");
  if (!(file instanceof File)) {
    return Response.json({ error: "Missing audio file" }, { status: 400 });
  }
  if (file.size === 0) {
    return Response.json({ error: "The audio file is empty" }, { status: 400 });
  }
  if (file.size > MAX_AUDIO_BYTES) {
    return Response.json(
      { error: "File too large for the hosted limit (4 MB). Run locally or see the README for large files." },
      { status: 413 },
    );
  }
  const language = normalizeLanguage(form.get("language"));

  try {
    const res = await getCartesia().stt.transcribe({ file, model: "ink-whisper", language });
    return Response.json({
      transcript: res.text,
      duration: res.duration ?? null,
      language: res.language ?? language,
    });
  } catch (err) {
    if (err instanceof MissingKeyError) {
      return Response.json({ error: err.message }, { status: 503 });
    }
    if (err instanceof Cartesia.APIError && typeof err.status === "number") {
      return Response.json({ error: UPSTREAM_ERRORS[err.status] ?? "Transcription failed" }, { status: 502 });
    }
    return Response.json({ error: "Transcription failed" }, { status: 500 });
  }
}
```

`ink-whisper` is the model for file transcription. `ink-2` is for streaming and does not work on this endpoint. The file from `formData()` goes to the SDK as it is. Send a `language` code (ISO 639-1) if the meeting is not in English; `normalizeLanguage` in `lib/limits.ts` checks it against a list of supported languages and falls back to English. `MAX_AUDIO_BYTES` in the same file is 4 MB. The SDK sends the `Cartesia-Version` header for you. Upstream errors map to fixed messages and a 502, so the provider's error body never reaches the page.

## Server: summarize

```ts filename="lib/schema.ts"
import { z } from "zod";

export const MeetingNotesSchema = z.object({
  title: z.string().describe("Short title, under 80 characters"),
  summary: z.string().describe("Neutral third-person summary, 3 to 6 sentences"),
  decisions: z
    .array(z.string())
    .describe(
      "Decisions that were made, one sentence each. Empty array if none. Do not include open questions or proposals nobody agreed to.",
    ),
  actionItems: z.array(
    z.object({
      task: z.string().describe("Short, imperative, self-contained"),
      owner: z.string().nullable().describe("Person named as responsible, or null"),
    }),
  ),
});

export type MeetingNotes = z.infer<typeof MeetingNotesSchema>;

export type ActionItem = {
  id: string;
  task: string;
  owner: string | null;
  done: boolean;
};

export type MeetingStatus = "transcribing" | "summarizing" | "ready" | "error";

export type Meeting = {
  id: string;
  createdAt: number;
  title: string;
  language: string;
  durationSec?: number;
  status: MeetingStatus;
  error?: string;
  transcript?: string;
  summary?: string;
  decisions: string[];
  actionItems: ActionItem[];
};
```

```ts filename="lib/prompt.ts"
export const NOTES_INSTRUCTIONS = `You turn meeting transcripts into notes.

Rules:
- Write the notes in the language of the transcript.
- Only use what the transcript says. Never invent owners, dates or decisions.
- A decision is something the participants agreed or settled. Proposals nobody agreed to and open questions are not decisions. If there are none, return an empty decisions array.
- An action item is a task someone committed to or was asked to do. Set owner to the person's name only if the transcript names them, otherwise null.
- The transcript has no speaker labels. Do not guess who said what.
- Ignore filler words and small talk.`;
```

```ts filename="app/api/summarize/route.ts"
import { generateText, NoObjectGeneratedError, NoOutputGeneratedError, Output } from "ai";
import { getModel, LlmConfigError } from "@/lib/llm";
import { MAX_TRANSCRIPT_CHARS } from "@/lib/limits";
import { NOTES_INSTRUCTIONS } from "@/lib/prompt";
import { clientIp, createRateLimiter, tooManyRequests } from "@/lib/rate-limit";
import { MeetingNotesSchema } from "@/lib/schema";

export const runtime = "nodejs";
export const maxDuration = 60;

const allow = createRateLimiter(10, 60_000);

export async function POST(req: Request) {
  if (!allow(clientIp(req))) return tooManyRequests();
  const body = await req.json().catch(() => null);
  const transcript = typeof body?.transcript === "string" ? body.transcript.trim() : "";
  if (!transcript) {
    return Response.json({ error: "The transcript is empty" }, { status: 400 });
  }
  if (transcript.length > MAX_TRANSCRIPT_CHARS) {
    return Response.json(
      { error: "The transcript is too long to summarize in one pass (about 120,000 characters)" },
      { status: 413 },
    );
  }

  try {
    const result = await generateText({
      model: getModel(),
      instructions: NOTES_INSTRUCTIONS,
      prompt: transcript,
      output: Output.object({ schema: MeetingNotesSchema }),
      temperature: 0.2,
      maxOutputTokens: 1500,
      maxRetries: 2,
    });
    const notes = result.output;
    return Response.json({ ...notes, title: notes.title.slice(0, 80), summary: notes.summary.slice(0, 1200) });
  } catch (err) {
    if (err instanceof LlmConfigError) {
      return Response.json({ error: err.message }, { status: 503 });
    }
    if (NoObjectGeneratedError.isInstance(err) || NoOutputGeneratedError.isInstance(err)) {
      return Response.json({ error: "The model did not return valid notes" }, { status: 502 });
    }
    return Response.json({ error: "Could not generate notes. Check the LLM key and model id." }, { status: 500 });
  }
}
```

The schema makes every key required, and `owner` is nullable instead of optional. OpenAI's strict structured outputs reject optional keys, and this shape works with the other providers too. The `describe` text on `decisions` matters. Without it, models list open questions as decisions. `getModel()` in `lib/llm.ts` reads `LLM_MODEL` and accepts an AI Gateway key or an OpenAI or Anthropic key directly. `MAX_TRANSCRIPT_CHARS` in `lib/limits.ts` is 120,000.

## Client: record and post

```tsx filename="app/record/page.tsx" standalone
'use client';

import { useRef, useState } from 'react';

export default function Page() {
  const recorder = useRef<MediaRecorder | null>(null);
  const chunks = useRef<Blob[]>([]);
  const [recording, setRecording] = useState(false);
  const [notes, setNotes] = useState<unknown>(null);

  async function start() {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
    const mimeType = ['audio/webm;codecs=opus', 'audio/mp4', 'audio/ogg;codecs=opus'].find(
      t => MediaRecorder.isTypeSupported(t),
    );
    const r = new MediaRecorder(stream, { mimeType, audioBitsPerSecond: 24_000 });
    chunks.current = [];
    r.ondataavailable = e => chunks.current.push(e.data);
    r.onstop = async () => {
      stream.getTracks().forEach(t => t.stop());
      const type = r.mimeType;
      const ext = type.startsWith('audio/mp4') ? 'm4a' : type.startsWith('audio/ogg') ? 'ogg' : 'webm';

      const form = new FormData();
      form.append('file', new Blob(chunks.current, { type }), `meeting.${ext}`);
      const t = await fetch('/api/transcribe', { method: 'POST', body: form }).then(r => r.json());

      const n = await fetch('/api/summarize', {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ transcript: t.transcript }),
      }).then(r => r.json());
      setNotes(n);
    };
    r.start(1000);
    recorder.current = r;
    setRecording(true);
  }

  function stop() {
    recorder.current?.stop();
    setRecording(false);
  }

  return (
    <div>
      <button onClick={recording ? stop : start}>{recording ? 'Stop' : 'Record'}</button>
      <pre>{JSON.stringify(notes, null, 2)}</pre>
    </div>
  );
}
```

This page is a minimal version you can drop into your own app. The template keeps `app/page.tsx` for the meeting list, moves recording into `lib/use-recorder.ts`, stops at 3.6 MB, and creates and resumes an `AudioContext` inside the click handler for its level meter, because Safari only starts audio from a user gesture.

Chrome and Firefox record `audio/webm` or `audio/ogg`. Safari records `audio/mp4`. The code picks the first type the browser supports and names the file to match. At 24 kbps, 20 minutes of speech is about 3.6 MB.

## How it works

1. `MediaRecorder` collects Opus chunks in the browser. On stop, the page posts the blob as form data.
2. `/api/transcribe` forwards the file to Cartesia and returns the text. The key stays on the server.
3. `/api/summarize` calls `generateText` with `Output.object`. The SDK validates the model's JSON against the zod schema and throws if it does not match, so `output` is always the right shape.

The speech-to-text endpoint returns no speaker labels. An action item's owner is only as good as the names spoken in the meeting, and the prompt tells the model not to guess.

## Limits

- Vercel serverless functions reject request bodies over 4.5 MB. That cap comes from the host, not from the Cartesia API. The template stays under it: uploads stop at 4 MB, and the recorder stops at 3.6 MB or 20 minutes, whichever comes first (`lib/limits.ts`). For longer meetings, run the route somewhere without that limit.
- The summarize route sends the whole transcript in one call. A very long transcript needs chunking, which this recipe does not do.
- Both routes spend your credits for anyone who can reach them. The template's `proxy.ts` asks for `APP_PASSWORD` (HTTP Basic auth) on every page and route when it is set, and on Vercel the app returns 503 until you set it, or set it to `none` to make the app public. The rate limit only slows casual abuse; the password is the real guard.
