# Build a browser voice chat with a Managed Agent

This recipe builds a voice chat page. You press a button, talk to an agent, and can cut in while it is speaking. The browser sends microphone audio straight to Cartesia and plays the agent's audio. Your server only creates the agent once and mints a short-lived token for each call, so the API key never reaches the page.

The finished app is in [`examples/voice-chat`](../../../examples/voice-chat/README.md). The folder runs on its own. The UI is shadcn/ui components in `components/ui/`, and the WebSocket client in `lib/agents-web/` is a copy of [`packages/agents-web`](../../../packages/agents-web/README.md).

## Prerequisites

- A Cartesia API key
- Node 22.13 or newer and pnpm 10
- A Next.js 16 app, or the example from this repo
- The basics of the agent connection from [Connect to a Managed Agent from the browser](./01-talk-to-a-managed-agent.mdx)

Agent LLM usage is billed to your Cartesia account.

The managed variant was run against the live API on 2026-10-14: agent creation, the token route, and a WebSocket session with a spoken question, a reply, and an interruption of the greeting. The browser microphone path was not tested with a real device, and the own-LLM code is typechecked only.

## Create the agent

A Managed Agent is created once, with a system prompt and a voice. The setup script does it and writes the id to `.env.local`.

```sh
cd examples/voice-chat
pnpm install
cp .env.example .env.local   # add CARTESIA_API_KEY
pnpm setup:agent
```

`@cartesia/cartesia-js` 4.2.0 has no typed method for creating a Managed Agent. Its `agents` resource still describes the older agent shape. The script therefore uses the client's generic `post`, which keeps the auth header, the retries and the `Cartesia-Version` header. The response type is declared next to the call.

```ts filename="scripts/setup-agent.ts"
export function buildBody(env: Env) {
  const config = {
    instructions: INSTRUCTIONS,
    initial_message: INITIAL_MESSAGE,
    model: { id: env.AGENT_MODEL_ID || DEFAULT_MODEL_ID },
    language: { primary: "en" },
    audio: { output: { voice_id: env.CARTESIA_VOICE_ID || DEFAULT_VOICE_ID } },
    speculative_generation: true,
    turn: { inactivity_check_in_secs: 10, inactivity_end_call_secs: 120 },
  };
  return {
    name: "Cookbook voice chat",
    description: "Created by examples/voice-chat in the Cartesia cookbook",
    config,
  };
}
```

The create call itself is one line. `AGENTS_PATH` is `/v1/agents`, and the default model is `claude-haiku-4.5`, both set in `scripts/paths.ts`.

```ts filename="scripts/setup-agent.ts"
agent = await client.post<CreatedAgent>(AGENTS_PATH, { body: buildBody(env) });
```

The real script also checks that the voice exists (`client.voices.get`) and that the model id is in `GET /v1/agents/models`, and it stops with the list of available ids if it is not. Model ids change, so set `AGENT_MODEL_ID` from that list rather than trusting the default. It reuses the saved agent on a second run, and `--dry-run` prints the request without a key.

Two details about the config:

- The agent speaks with Sonic 3.6 because that is the platform default. The config has a voice id but no text to speech model field, so there is nothing to set.
- Write the prompt for the ear. One or two short sentences, no lists or markdown, numbers spelled out, one question at a time. Those rules are in `scripts/prompt.ts`.

## Mint a token

The browser needs a token to open the WebSocket. This route creates one that lasts 60 seconds and carries only the `agent` grant, so it cannot be used for speech synthesis or transcription.

```ts filename="app/api/token/route.ts"
import { createTokenRoute } from "../../../lib/token-handler";

export const POST = createTokenRoute();
```

`createTokenRoute` wraps the `createAgentTokenHandler` helper from the vendored client.

```ts filename="lib/token-handler.ts"
export function createTokenRoute(allow = createRateLimiter(10, 60_000)) {
  return async function POST(req: Request): Promise<Response> {
    const apiKey = getApiKey();
    if (!apiKey) {
      return Response.json(
        { error: "CARTESIA_API_KEY is not set. Add it to .env.local and restart." },
        { status: 503, headers },
      );
    }
    const handler = createAgentTokenHandler({
      apiKey,
      expiresIn: 60,
      authorize: (r) => allow(r.headers.get("x-forwarded-for")?.split(",")[0]?.trim() || "local"),
    });
    const res = await handler(req);
    if (res.status === 401) {
      return Response.json({ error: "Too many requests. Try again in a minute." }, { status: 429, headers });
    }
    return res;
  };
}
```

It returns a plain 503 when `CARTESIA_API_KEY` is missing, and it answers 429 after 10 requests a minute per address. That limit lives in memory on one server instance, and `x-forwarded-for` can be spoofed unless a trusted proxy sets it, so treat it as a demo guard. Before you deploy, replace `authorize` with your own session check, as in [Browser auth with access tokens](../00-guides/01-browser-auth-with-access-tokens.mdx). Anyone who can call this route can start calls on your account.

The agent id is not secret. The page reads `CARTESIA_AGENT_ID` on the server and passes it down as a prop.

## Connect from the browser

`useCartesiaAgent` does the work: it asks for the microphone, opens the socket, sends `session_create` first, streams microphone audio in 40 ms chunks, plays the agent's audio, and drops queued audio the moment the agent is interrupted.

```tsx filename="components/voice-chat.tsx"
"use client";

import { useCartesiaAgent } from "@/lib/agents-web/react";
import { VoiceChatView } from "./voice-chat-view";

async function getToken(): Promise<string> {
  const res = await fetch("/api/token", { method: "POST" });
  const body = (await res.json().catch(() => ({}))) as { token?: string; error?: string };
  if (!res.ok || !body.token) throw new Error(body.error ?? `Token request failed (${res.status})`);
  return body.token;
}

export function VoiceChat({ agentId }: { agentId: string }) {
  const agent = useCartesiaAgent({
    agentId,
    getToken,
    // Echo cancellation is the default in agents-web; the 16 kHz input format is too.
    // outputDelivery stays "as_available": the client owns the playback queue, which is
    // what lets it drop audio the moment the agent is interrupted.
  });

  return (
    <VoiceChatView
      status={agent.status}
      messages={agent.messages}
      userSpeaking={agent.isSpeaking.user}
      agentSpeaking={agent.isSpeaking.agent}
      muted={agent.muted}
      error={agent.error ? { code: agent.error.code, message: agent.error.message } : null}
      onStart={() => void agent.start().catch(() => {})}
      onStop={() => void agent.stop()}
      onToggleMute={() => agent.setMuted(!agent.muted)}
    />
  );
}
```

Call `start()` from a click. Browsers only allow the microphone and audio playback after a user gesture. `getToken` runs once per `start()`, so a retry always gets a fresh token.

The component is split in two. `components/voice-chat.tsx` holds the hook and `components/voice-chat-view.tsx` takes plain props, so the tests render every state (connecting, speaking, interrupted, error) without a socket.

These are the server events the client handles for you.

| Event | What the client does |
| --- | --- |
| `session_ready` | Marks the call ready and starts sending microphone audio |
| `audio_output` | Decodes the audio and queues it for playback |
| `audio_output_clear` | Empties the playback queue at once |
| `turn_started`, `turn_output_text_delta`, `turn_ended` | Builds the transcript |
| `client_tool_call` | Runs the handler you pass in `tools` and sends the result back |
| `error` | Surfaces it, and a fatal one ends the call |

## Captions and barge-in

Assistant text streams in word by word as the agent speaks. Each `turn_output_text_delta` is appended as is, because the deltas already contain their spaces. When the turn ends, the server's final `text` replaces the streamed text.

Your own words are different. The service sends user text only when your turn ends, in `turn_ended`. While you are speaking, the example shows animated dots, then the text when the turn closes. If you need partial user captions, use your own LLM as described below, where Ink-2 sends them.

Barge-in is handled in two places. The service stops generating when it hears you and sends `audio_output_clear`, and the client empties its playback queue. The assistant turn then ends with `interrupted: true`, and its `text` holds only what the agent actually said. Replacing the streamed text with it cuts the bubble to the spoken words. The example adds a small "interrupted" tag under it.

Use headphones. Without echo cancellation the microphone hears the speakers and the agent interrupts itself. The client asks the browser for echo cancellation, noise suppression and automatic gain, which helps but is not perfect.

## Use your own LLM

The managed agent picks the LLM from Cartesia's list. If you want any other model, or full control of the loop, run the pieces yourself: Ink-2 for speech to text, your model through the AI SDK, and Sonic 3.6 for speech. This is a design with typechecked code, not a second app. It has not been run against the live API, so test it before you rely on it.

Everything talks to Cartesia from the browser with a token that has the `stt` and `tts` grants. The code lives in [`examples/voice-chat/byo-snippets`](../../../examples/voice-chat/byo-snippets/speak.ts), which the template typechecks but does not run. In your app, put `token-route.ts` at `app/api/token/route.ts` (the session fetches `/api/token`), `chat-route.ts` at `app/api/chat/route.ts`, and the other four files in `lib/`.

```ts filename="byo-snippets/token-route.ts"
import Cartesia from "@cartesia/cartesia-js";

export async function POST(): Promise<Response> {
  const apiKey = process.env.CARTESIA_API_KEY;
  if (!apiKey) {
    return Response.json({ error: "CARTESIA_API_KEY is not set." }, { status: 503 });
  }
  const client = new Cartesia({ apiKey });
  const { token } = await client.accessToken.create({
    grants: { stt: true, tts: true },
    expires_in: 60,
  });
  return Response.json({ token }, { headers: { "Cache-Control": "no-store" } });
}
```

Your model sits behind a route that streams text. Set `LLM_MODEL` to a model id your AI SDK setup accepts.

```ts filename="byo-snippets/chat-route.ts"
import { streamText, type LanguageModel } from "ai";

const model: LanguageModel = process.env.LLM_MODEL as string;

const SYSTEM = "You are a voice assistant. Reply in one or two short sentences. No markdown, no lists.";

export async function POST(req: Request): Promise<Response> {
  const { messages } = (await req.json()) as {
    messages: { role: "user" | "assistant"; content: string }[];
  };
  const result = streamText({
    model,
    system: SYSTEM,
    messages,
    abortSignal: req.signal,
  });
  return result.toTextStreamResponse();
}
```

Listening has two parts. The first captures the microphone as Float32 in 100 ms chunks. The second sends those chunks to `client.stt.autoFinalize.websocket` with the `ink-2` model and turns the events into captions. `turn.update` gives live partial text for the user. On `turn.end`, append `transcript` exactly as it is, without trimming or adding spaces.

```ts filename="byo-snippets/mic.ts"
const CHUNK_MS = 100;

export async function startMic(audioCtx: AudioContext, onChunk: (chunk: ArrayBuffer) => void) {
  const workletSource = `
    class PCMCapture extends AudioWorkletProcessor {
      process(inputs) {
        const ch = inputs[0]?.[0];
        if (ch) this.port.postMessage(ch);
        return true;
      }
    }
    registerProcessor('pcm-capture', PCMCapture);
  `;
  const url = URL.createObjectURL(new Blob([workletSource], { type: "application/javascript" }));
  await audioCtx.audioWorklet.addModule(url);
  URL.revokeObjectURL(url);

  const stream = await navigator.mediaDevices.getUserMedia({
    audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true },
  });
  const source = audioCtx.createMediaStreamSource(stream);
  const node = new AudioWorkletNode(audioCtx, "pcm-capture");

  const chunkSamples = Math.round((audioCtx.sampleRate * CHUNK_MS) / 1000);
  let pending = new Float32Array(0);
  node.port.onmessage = (e: MessageEvent<Float32Array>) => {
    const joined = new Float32Array(pending.length + e.data.length);
    joined.set(pending);
    joined.set(e.data, pending.length);
    let offset = 0;
    while (joined.length - offset >= chunkSamples) {
      onChunk(joined.slice(offset, offset + chunkSamples).buffer);
      offset += chunkSamples;
    }
    pending = joined.slice(offset);
  };
  source.connect(node);

  return {
    stop() {
      source.disconnect();
      node.disconnect();
      stream.getTracks().forEach((t) => t.stop());
    },
  };
}
```

```ts filename="byo-snippets/listen.ts"
import type Cartesia from "@cartesia/cartesia-js";
import { startMic } from "./mic";

export interface ListenHandlers {
  onTurnStart(): void;
  onPartial(transcript: string): void;
  onTurnEnd(transcript: string): void;
}

export async function listen(client: Cartesia, audioCtx: AudioContext, handlers: ListenHandlers) {
  const ws = client.stt.autoFinalize.websocket({
    model: "ink-2",
    encoding: "pcm_f32le",
    sample_rate: audioCtx.sampleRate,
  });
  ws.on("error", (err) => console.error(err.message));

  const mic = await startMic(audioCtx, (chunk) => ws.sendRaw(chunk));

  const done = (async () => {
    for await (const event of ws.stream()) {
      if (event.type !== "message") continue;
      const m = event.message;
      if (m.type === "turn.start") handlers.onTurnStart();
      else if (m.type === "turn.update") handlers.onPartial(m.transcript);
      else if (m.type === "turn.end") handlers.onTurnEnd(m.transcript);
    }
  })();

  return {
    done,
    stop() {
      mic.stop();
      ws.send({ type: "close" });
    },
  };
}
```

Speaking opens one text to speech context per reply. The sentence splitter lets the first sentence start playing while the model is still writing the rest. Chunks are scheduled back to back on the Web Audio clock. With `add_timestamps` on, you know which words have been played, which you need for barge-in.

```ts filename="byo-snippets/speak.ts"
import type Cartesia from "@cartesia/cartesia-js";

const SAMPLE_RATE = 44100;

export function takeSentences(buffer: string): { sentences: string[]; rest: string } {
  const sentences: string[] = [];
  let rest = buffer;
  for (;;) {
    const m = rest.match(/^([\s\S]*?[.!?])\s+/);
    if (!m) break;
    sentences.push(m[1]!);
    rest = rest.slice(m[0].length);
  }
  return { sentences, rest };
}

export interface Speaker {
  speak(text: AsyncIterable<string>, onWords?: (spoken: string) => void): Promise<void>;
  cancel(): Promise<string>;
  readonly speaking: boolean;
}

export async function createSpeaker(client: Cartesia, audioCtx: AudioContext, voice: string): Promise<Speaker> {
  const ws = await client.tts.websocket();
  ws.on("error", (err) => console.error(err.message));

  let ctx: ReturnType<typeof ws.context> | null = null;
  let sources: AudioBufferSourceNode[] = [];
  let nextStart = 0;
  let replyStart = 0;
  let words: { word: string; start: number }[] = [];
  let speaking = false;

  const spokenSoFar = () => {
    const t = audioCtx.currentTime - replyStart;
    return words.filter((w) => w.start <= t).map((w) => w.word).join(" ");
  };

  return {
    get speaking() {
      return speaking;
    },

    async speak(text, onWords) {
      const current = ws.context({
        model_id: "sonic-3.6",
        voice,
        output_format: { container: "raw", encoding: "pcm_f32le", sample_rate: SAMPLE_RATE },
        language: "en",
        add_timestamps: true,
        max_buffer_delay_ms: 0,
      });
      ctx = current;
      sources = [];
      words = [];
      speaking = true;
      nextStart = Math.max(nextStart, audioCtx.currentTime);
      replyStart = nextStart;

      const playing = (async () => {
        for await (const event of current.receive()) {
          if (event.type === "chunk" && event.audio) {
            const floats = new Float32Array(event.audio.buffer, event.audio.byteOffset, event.audio.byteLength / 4);
            const buffer = audioCtx.createBuffer(1, floats.length, SAMPLE_RATE);
            buffer.getChannelData(0).set(floats);
            const source = audioCtx.createBufferSource();
            source.buffer = buffer;
            source.connect(audioCtx.destination);
            const at = Math.max(nextStart, audioCtx.currentTime);
            source.start(at);
            nextStart = at + buffer.duration;
            sources.push(source);
          } else if (event.type === "timestamps" && event.word_timestamps) {
            const w = event.word_timestamps;
            w.words.forEach((word, i) => words.push({ word, start: w.start[i] ?? 0 }));
            onWords?.(spokenSoFar());
          } else if (event.type === "error") {
            console.error(event.title, event.message);
          }
        }
        speaking = false;
      })();

      let buffer = "";
      for await (const piece of text) {
        buffer += piece;
        const { sentences, rest } = takeSentences(buffer);
        buffer = rest;
        for (const transcript of sentences) await current.push({ transcript });
      }
      if (buffer.trim()) await current.push({ transcript: buffer });
      await current.no_more_inputs();
      await playing;
    },

    async cancel() {
      const spoken = spokenSoFar();
      await ctx?.cancel();
      for (const s of sources) {
        s.stop();
        s.disconnect();
      }
      sources = [];
      nextStart = audioCtx.currentTime;
      speaking = false;
      return spoken;
    },
  };
}
```

The session ties them together. When Ink-2 reports `turn.start` while the agent is still talking, the session aborts the LLM request, cancels the TTS context with `ctx.cancel()`, stops every scheduled audio node, and cuts the assistant message to the words already spoken.

```ts filename="byo-snippets/session.ts"
import Cartesia from "@cartesia/cartesia-js";
import { listen } from "./listen";
import { createSpeaker } from "./speak";

type Message = { role: "user" | "assistant"; content: string };

async function* readText(res: Response): AsyncGenerator<string> {
  const reader = res.body!.pipeThrough(new TextDecoderStream()).getReader();
  for (;;) {
    const { done, value } = await reader.read();
    if (done) return;
    yield value;
  }
}

export async function startVoiceChat(opts: {
  voice: string;
  onCaption(text: string): void;
  onMessages(messages: Message[]): void;
}) {
  const { token } = await (await fetch("/api/token", { method: "POST" })).json();
  const client = new Cartesia({ token });
  const audioCtx = new AudioContext();
  const speaker = await createSpeaker(client, audioCtx, opts.voice);

  const messages: Message[] = [];
  let llm: AbortController | null = null;

  const bargeIn = async () => {
    if (!speaker.speaking && !llm) return;
    llm?.abort();
    llm = null;
    const spoken = await speaker.cancel();
    const last = messages[messages.length - 1];
    if (last?.role === "assistant") last.content = spoken;
    opts.onMessages([...messages]);
  };

  const listening = await listen(client, audioCtx, {
    onTurnStart: () => void bargeIn(),
    onPartial: opts.onCaption,
    onTurnEnd: async (transcript) => {
      opts.onCaption("");
      messages.push({ role: "user", content: transcript });
      messages.push({ role: "assistant", content: "" });
      opts.onMessages([...messages]);

      const controller = new AbortController();
      llm = controller;
      try {
        const res = await fetch("/api/chat", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ messages: messages.slice(0, -1) }),
          signal: controller.signal,
        });
        await speaker.speak(readText(res), (spoken) => {
          messages[messages.length - 1]!.content = spoken;
          opts.onMessages([...messages]);
        });
      } catch (err) {
        if ((err as Error).name !== "AbortError") throw err;
      } finally {
        if (llm === controller) llm = null;
      }
    },
  });

  return {
    async stop() {
      listening.stop();
      await bargeIn();
      await audioCtx.close();
    },
  };
}
```

How the two approaches compare:

- The managed agent is fewer moving parts. You run one token route, the service owns turn taking, and the LLM comes from Cartesia's list. Custom retrieval has to go through webhook or client tools.
- Your own LLM gives you any model and every step of the loop. You also own the turn logic, the barge-in code above, the cost of each service, and the browser audio details.

With the managed agent the service does the equivalent of that barge-in work on its side, and the client only empties its playback queue.

## Troubleshooting

- **The page says "Create the agent first".** `CARTESIA_AGENT_ID` is not set. Run `pnpm setup:agent` and restart the server.
- **The token request fails with 503.** `CARTESIA_API_KEY` is missing from `.env.local`.
- **The call closes right away with 1008.** The service rejected the first event or the token. Check that the token is fresh and the agent id belongs to the account that minted it.
- **The call ends after two minutes of silence.** The service closes a session that gets no client event for 120 seconds. The client keeps sending silence while the microphone is muted, so this means something stopped the page, such as a suspended tab.
- **The agent answers itself or cuts out.** Echo. Use headphones.
- **Audio sounds garbled or fast.** If you write your own client, the sample rate you declare in `input_format` must match the audio you send. The `agents-web` client resamples to 16 kHz for you.
- **The microphone is blocked.** Allow it for the site in the browser. It needs HTTPS or `localhost`.
- **A `model_sunsetted` error in the own-LLM variant.** The text to speech model id you passed has been retired. Use `sonic-3.6`.
