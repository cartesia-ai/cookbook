# Agents

Recipes for Cartesia Managed Agents, which run speech to text, the LLM and text to speech on Cartesia's side. Your app moves audio and answers tool calls.

- [Connect to a Cartesia Managed Agent from the browser](./01-talk-to-a-managed-agent.mdx): mint an `agent` token and open the agent WebSocket, with the events you send and receive.
- [Build a browser voice chat with a Managed Agent](./02-voice-chat.mdx): a Next.js call page with barge-in and live captions, plus a variant with your own LLM.
- [Build an AI language speaking partner with a Managed Agent](./03-speaking-partner.mdx): role plays in five languages, a temporary agent per session, and written corrections after every line.
- [Add voice search to your docs with a Managed Agent and client tools](./04-voice-search-for-your-docs.mdx): a one script tag widget whose agent searches your docs through a client tool and scrolls to the cited section.
